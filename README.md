# OVO俱樂部幣號自動發放系統

包含：
- 手機/電腦響應式客戶端
- 管理員後台（建立專屬密鑰、設定到期時間、匯入帳密）
- 密鑰驗證與一次性領取
- 依資料庫 ID 順序發放庫存
- 發放紀錄與簡易統計
- SQLite 交易防止同一密鑰或同一帳號重複發放

## 本機啟動

需要 Node.js 20 或更新版本。

```bash
npm install
```

設定管理員權杖（請換成自己產生的長隨機字串，不要用範例值）：

Windows PowerShell：
```powershell
$env:ADMIN_TOKEN="請替換成至少24字元的隨機秘密字串"
npm start
```

macOS/Linux：
```bash
export ADMIN_TOKEN="請替換成至少24字元的隨機秘密字串"
npm start
```

瀏覽器開啟 http://localhost:3000

## 使用方式

1. 點「管理員後台」，輸入 `ADMIN_TOKEN`。
2. 在「匯入帳號密碼」每行輸入 `帳號,密碼`，按匯入。
3. 建立一組或多組密鑰，完整密鑰只在建立時顯示一次，請複製並安全交給客戶。
4. 客戶在「客戶領取」頁面輸入密鑰，驗證後領取一次。
5. 後台可查看密鑰狀態、剩餘庫存與領取紀錄。

## 正式部署前重要事項

- 此專案是可啟動的入門版，不代表已經公開上線；目前網站檔案需要部署到支援 Node.js 的主機。
- `ADMIN_TOKEN` 必須設定為高熵隨機值並只放在伺服器環境變數，不能寫入前端。
- 若部署環境的磁碟是暫存或多副本環境，不要直接依賴本機 SQLite；改用 PostgreSQL 等持久化資料庫，並將「密鑰狀態更新＋帳號分配」放在同一資料庫交易內。
- 正式公開使用前，建議加上 HTTPS、備份、監控、管理員登入/多因素驗證、操作稽核、IP/帳號速率限制，以及 CSV 匯入驗證。
- 本版本將密鑰以 SHA-256 雜湊儲存，原始密鑰只在建立時顯示一次。帳號密碼需要以可還原形式交付，因此資料庫應限制權限並加密備份。
- 本系統只應發放你有權管理和轉交的帳號；不要匯入他人未授權的帳號或密碼。
